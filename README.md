# Pomotop
![banner](./static/readmebanner.png)

A Pomodoro timer that resides neatly on the top of your screen as a notch. Minimal, non distracting and just works

## Features
- Pomodoro Timer with customizable time
- A mini timer that shows when timer is running. 
- Really small app size
- Low Resource Usage for efficiency

## Installation
### Prebuilt Version
Go to the releases section of this repository then download and install the latest version or Pomotop
> [Releases Page](https://github.com/akshdzn/Pomotop/releases)
### Compiling from source
**Prerequisites** : [Tauri](https://github.com/tauri-apps/tauri) , [Rust](https://rust-lang.org/), [NodeJS](https://nodejs.org/en) 
> NodeJS alternatives like Deno and Bun might work but are untested
1. Clone this repository
```
git clone https://github.com/akshdzn/Pomotop.git
```
2. Enter the directory and run this command to build the app
```
npm run tauri build
```
Or use this command to preview for debugging / coding
```
npm run tauri build
```
